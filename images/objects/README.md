# Objects

Single-object cutouts for compact mockups, drag-and-drop tests, and compositing samples.

## Rules

- Use a 250×250 px PNG canvas.
- Keep the background genuinely transparent and preserve the alpha channel.
- Show exactly one complete object with clear space around it.
- Do not include a floor, backdrop, cast shadow, reflection, hand, text, logo, watermark,
  or border.
- Use lowercase `kebab-case` names that describe the object and end in `-250x250.png`.
- Keep subjects fictional and unbranded.
