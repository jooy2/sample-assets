   :CUSTOM_ID: drawers

   :Effort:   2h
   :END:

* Text formatting

  *bold*, /italic/, _underlined_, =verbatim=, ~code~, +struck through+, and
  combinations like */bold italic/*.

  Subscripts and superscripts: H_2O and E = mc^2, with braces for anything
  longer than a character: x_{i+1} and 2^{32}.

  Entities: \alpha \beta \gamma, \to, \Rightarrow, \pm, \deg, \nbsp, and
  \ldots{} followed by text.

  A line break is forced with a trailing backslash-backslash \\
  like this.

** Description
   - archive :: One file holding an index and every object it refers to.
   - object :: A byte stream stored under the digest of its own contents.
   - digest :: Thirty-two bytes identifying an object uniquely.

** Checkboxes
   - [-] Partially complete parent [1/3]
     - [X] Done
     - [ ] Not done
     - [ ] Also not done

   - [ ] A parent with a percentage cookie [0%]
     - [ ] One
     - [ ] Two

* Tables

  A plain table, with an alignment row and a formula:

  | Route          | Passengers | Recovery |
  |----------------+------------+----------|
  | Harbour Loop   |      83755 |     127% |
  | Kestrel Point  |      63325 |     103% |
  | Halloway       |      30615 |      68% |
  | Night Crossing |      37185 |     103% |
  |----------------+------------+----------|
  | Total          |     214880 |          |
  #+TBLFM: @>$2=vsum(@2..@-1)

  A table with a caption and a name, so it can be referenced:

  #+CAPTION: Exit codes returned by the command-line tool
  #+NAME: tbl-exit-codes
  | Code | Meaning                          |
  |------+----------------------------------|
  |    0 | Success                          |
  |    1 | Usage error                      |
  |    2 | Archive not found or unreadable  |
  |    3 | Verification failed              |
  |    4 | Interrupted; archive resumable   |

  See [[tbl-exit-codes]] for the full list.

* Timestamps

  - Active, appearing in the agenda: <2027-09-02 Thu>
  - Inactive, not appearing in the agenda: [2027-09-02 Thu]
  - With a time: <2027-09-02 Thu 10:00>
  - A range: <2027-09-02 Thu 10:00-11:00>
  - A date range: <2027-10-01 Fri>--<2027-10-29 Fri>
  - Repeating weekly: <2027-09-06 Fri 07:00 +1w>
  - With a warning period: <2027-09-30 Thu -3d>
