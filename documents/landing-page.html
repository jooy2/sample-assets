Run only what changed.

Kestrel hashes your task inputs, skips everything it has already built, and gets out of the way. Four commands, one config file, no daemon.

Get started Read the docs 

$ npm install --global kestrel
$ kestrel run test
  build   cached  0.2s
  test    ran     4.8s
done in 5.0s

What it does

Content-addressed cache

Keys come from file contents, not timestamps, so a checkout is still a hit.

Dependency graph

Declare what a task needs; Kestrel works out the order and the parallelism.

Watch mode

Re-runs a task when one of its declared inputs changes, and nothing else.

Readable output

One line per task, colour when it helps, plain text when piped.
