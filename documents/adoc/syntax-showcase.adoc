== Text formatting

_Italic_, *bold*, `monospace`, #highlighted#, ~subscript~, ^superscript^, and
+++<em>passthrough HTML</em>+++.

Constrained and unconstrained forms differ: *bold word* against
**bold**inside**a**word.

Attribute references expand inline: this page documents {product} {version}.

Escaping uses a backslash: \*not bold\* and \{product} stays literal.

A line break at the end of a line is forced with a trailing plus: +
like this.

=== Mixed with continuation

. Run the command:
+
[source,console]
----
$ driftwood pack ./photos --into photos.dw
----
+
The archive is written to the current directory.

. Verify it:
+
[source,console]
----
$ driftwood verify photos.dw
----

=== Description list

archive:: One file holding an index and every object it refers to.
object:: A byte stream stored under the digest of its own contents.
+
An object has no name. Names live in the index.
digest:: Thirty-two bytes identifying an object uniquely.

== Admonitions

NOTE: A note carries information the reader can act on later.

TIP: Pass `--dry-run` first.

IMPORTANT: The index is rewritten in place during `gc`.

CAUTION: A short digest is for display only.

WARNING: Extended attributes are not preserved.

[NOTE]
====
A block admonition may contain more than a paragraph:

* a list,
* a code block,
* or another block entirely.
====
